# OutThink AI ($OUTTHINK)

> **High-Stakes Human Expert Evaluation Arena & Private Benchmark Dataset Platform**

OutThink AI pits verified human ground-truth expertise against frontier AI models (GPT-4o, Claude 3.5 Sonnet, Gemini 1.5 Pro, Llama 3.1 405B). When frontier models fail high-stakes edge traps, human experts earn `$OUTTHINK` emissions and protocol licensing yields.

## ⚡ Core Features

- **Live Duel Arena**: Interactive multi-model evaluation testing frontier LLMs on high-stakes clinical, legal, and financial edge cases.
- **3D Refraction Glass Cube**: Real-time Three.js WebGL refraction shader animating the `OutThink` brandmark across dynamic theme spectrums.
- **Cognitive Matrix**: Multi-axis radar diagram mapping machine blindspots across temporal latency, regulatory statute changes, cross-domain nuance, and numerical precision.
- **Case Vault**: Cryptographically verified zero-knowledge benchmark hashes with peer-reviewed consensus mechanisms.
- **Viral Cards Studio**: Custom 3D badge and card generator for human experts to showcase model defeat proofs.
- **$OUTTHINK Tokenomics (Live on pump.fun)
- Fair launched on Solana via pump.fun
- Dev 0% supply, community verified ground-truth mining**: Fixed supply emissions, staking pools, and dataset licensing distribution.

## 🚀 Deployment

### Deploy to Vercel
The repository is pre-configured with `vercel.json` supporting static SPA routing and mocked API routes:

```bash
vercel deploy
```

### Local Development
Run with any static HTTP server:

```bash
npx serve .
# or
python -m http.server 3000
```
